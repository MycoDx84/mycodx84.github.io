# MycoDx Website

MycoDx corporate website built with React, TypeScript, and Vite.

## Content Management

Product, News, and Gallery content can be managed through Pages CMS.

For staff upload instructions, see [CMS_GUIDE.md](CMS_GUIDE.md).

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
```
